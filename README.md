# پرزنتیشن تئوری بازی در رفتار شبکه‌ای

این پرزنتیشن یک ارائه تعاملی و مدرن با استفاده از React و Framer Motion است که به سبک Prezi طراحی شده است.

## نصب و راه‌اندازی

```bash
cd presentation
npm install
```

## اجرا

برای اجرای پرزنتیشن در حالت توسعه:

```bash
npm run dev
```

سپس در مرورگر به آدرس نمایش داده شده بروید (معمولاً http://localhost:5173).

## ساخت نسخه Production

```bash
npm run build
```

فایل‌های ساخته شده در پوشه `dist` قرار می‌گیرند.

## استفاده

- **کلیدهای جهت‌نما:** برای جابجایی بین اسلایدها استفاده کنید
  - `→` یا `↓`: اسلاید بعدی
  - `←` یا `↑`: اسلاید قبلی
- **دکمه‌های ناوبری:** در پایین صفحه برای جابجایی بین اسلایدها
- **نقطه‌ها:** برای رفتن مستقیم به یک اسلاید خاص کلیک کنید

## ویرایش اسلایدها

برای ویرایش یا اضافه کردن اسلاید جدید، فایل `src/data/slides.js` را ویرایش کنید.

هر اسلاید می‌تواند یکی از انواع زیر باشد:
- `bullet`: لیست نقطه‌ای
- `text`: متن پاراگراف
- `matrix`: ماتریس بازی

مثال ساختار اسلاید:

```javascript
{
  title: 'عنوان اسلاید',
  concept: 'مفهوم تئوری بازی',
  type: 'bullet', // یا 'text' یا 'matrix'
  points: ['نقطه ۱', 'نقطه ۲'],
  visualNote: 'یادداشت بصری'
}
```
